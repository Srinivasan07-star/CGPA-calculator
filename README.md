# 🎓 CGPA Calculator

A robust, console-based Python project designed to calculate a student's Cumulative Grade Point Average (CGPA) based on subject grades and credits. This project was created as part of my programming learning journey and demonstrates the practical application of core Python concepts and Object-Oriented Programming principles.

---

## 🎯 Objective

To develop a simple, user-friendly, and efficient CGPA Calculator that:
* Accepts student information and academic records.
* Validates inputs rigorously to prevent runtime errors.
* Processes grades and credits to compute the final CGPA accurately.
* Generates and displays a neat, professional student academic report.

---

## ✨ Features

* **Student Information Input:** Captures essential student details.
* **Subject-Wise Data Entry:** Easily input multiple subjects and their corresponding metrics.
* **Robust Input Validation:** Utilizes loops and exception handling to catch invalid grades, credits, or data types.
* **Accurate CGPA Calculation:** Computes total grade points and credits to derive the final CGPA.
* **Result Classification:** Automatically categorizes performance based on the calculated CGPA.
* **Object-Oriented Programming (OOP):** Built using clean class structures and object interactions.

## 🔄 Workflow

1. **Initialize:** Enter student personal and academic details.
2. **Subject Setup:** Specify the number of subjects to evaluate.
3. **Data Entry:** Input grades and credit hours for each subject.
4. **Validation:** System validates user inputs in real-time.
5. **Computation:** Calculates total grade points earned and total credits.
6. **Processing:** Computes the final CGPA.
7. **Report Generation:** Displays a neat, formatted student academic report and final classification.
